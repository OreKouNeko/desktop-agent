# desktop-agent

**极轻量级简易办公 GUI agent**（Windows） · `v0.1 测试版` · 作者：OreKouNeko

用自然语言指挥它操作 Word / Excel / PowerPoint。它读系统的无障碍树来定位控件，不靠截图猜坐标，整个项目不到 200 KB，没有本地模型，不需要显卡。

> **这是 0.1 测试版，请在理解它的局限之后再决定是否使用。**
> 它只在一台机器、二十四个固定场景上验证过。它不是通用桌面助手，也不会替你完成"大部分办公工作"。

---

## 它是什么

一个**受约束、可验证**的桌面自动化工具。你把一件边界清楚的事交给它，它一步一步操作真实窗口，并把每一步都记录下来。

适合的形状是：**目标明确、终态可校验、出错能人工复核**的重复操作。

## 它不是什么

这一节比上一节重要，请务必读完。

| 局限 | 具体表现 |
| --- | --- |
| **不通用** | 只验证过 24 个场景。邮件、合并文档、复杂排版、图表、宏，全部没有做 |
| **慢** | 单个操作 6–80 秒，比人慢一个数量级。不适合任何实时任务 |
| **依赖无障碍树** | 游戏、自绘界面、部分 Electron 应用里它几乎看不见东西 |
| **纯图形界面会失手** | 版式画廊、表格网格这类"只能看图选"的地方，成功率明显下降 |
| **会误判成功** | 它说"完成"不代表真的完成。所有不可逆操作都必须人工复核 |
| **只测过中文 Office** | 其他语言版本、其他 Office 版本未验证 |
| **单机单环境** | 只在一台 Windows 上跑过，兼容性未知 |

如果你需要的是"稳定替代人做办公"，这个项目现在**做不到**。

## 特点

- **极轻**：源码 176 KB，压缩包 66 KB。没有模型权重，没有 Electron，没有 Docker。
- **省内存**：常驻内存约 60 MB，默认硬上限 3 GB，运行中可随时中断。
- **可控**：`Ctrl+Alt+F12` 随时急停；看门狗超时自动收尾；不做全局键盘钩子（这会拖垮整机输入）。
- **可验证**：Office 场景用解析保存后的文件来判定成败，不看模型自述。
- **省钱**：一次操作通常 2–15 次模型调用。成功过的任务会存成技能，第二次**零调用**重放。
- **可读**：每次运行留下 `events.jsonl`、截图和 `meta.json`，出了问题能完整复盘。

## 快速开始

需要 Windows 10/11 与 Python 3.10+。

```bash
python -m venv .venv
.venvScriptspython -m pip install -e .
.venvScriptspython -m desktop_agent
```

或者直接双击 `run.bat`，首次运行会自动建环境。

启动后：填入 API Key（DPAPI 加密存本地）→ 选目标窗口 → 输入指令 → 点开始。

## 实测覆盖

二十四项，全部用解析文件的方式核实：

| 应用 | 已验证 |
| --- | --- |
| Word | 替换全文、加粗、斜体、居中、右对齐、设置字号、插入表格、另存为、打开文件 |
| Excel | 写单元格、公式、批量填格、长程多格、加粗、百分比格式、自动筛选、排序、另存为 |
| PowerPoint | 新增页、改标题、正文占位、加粗标题、删除页、更换版式（不稳） |
| 跨窗口 | 另存为对话框、打开文件对话框 |

## 工作原理

```
感知（无障碍树 + 可选截图）
      ↓
决策（云端模型，返回一步 JSON）
      ↓
执行（9 个原子动作）
      ↓
校验（重新采样，比对界面指纹）
```

三条原则：**能用无障碍树就不用截图**；**每个动作后都要有反馈**；**高频易错的组合封成一个原子动作**（写单元格、套格式、另存为）。

```
docs/             使用说明、工程手册、免责声明
```

## 安全

- API Key 只存在本地 `~/.desktop-agent/key.bin`，用 Windows DPAPI 加密，仅当前用户可解密，**不会上传到任何地方**
- 运行记录含屏幕截图，全部在本地，可随时整目录删除
- 不做遥测，不联网除模型接口外的任何服务
