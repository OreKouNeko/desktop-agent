## 1. 它会真的操作你的电脑

本程序通过系统 API 合成真实的鼠标和键盘输入。它点击的是**当前屏幕上的真实窗口**，不是沙箱里的模拟环境。这意味着：

- 如果你的指令有歧义，它可能点到你没预期的位置
- 它可能覆盖、修改、删除你的文件
- 运行期间请不要同时用鼠标键盘操作同一个窗口（会互相干扰）

**请勿在存有重要且无备份数据的机器上直接使用。**

## 2. 无法保证结果正确

即使程序报告"完成"，也只代表它认为完成了。本项目在 Office 场景下用解析文件的方式做了严格校验，但**通用场景下无法保证**。任何不可逆操作（删除、覆盖保存、发送、付款、提交表单）都应当人工复核。
