# 使用说明

## 1. 安装

需要 Windows 10/11 与 Python 3.10 以上。

```bash
cd desktop-agent
python -m venv .venv
.venvScriptspython -m pip install -e .
```

## 2. 配置 API Key

两种方式，任选其一：

**图形界面**：启动 `desktop-agent`，在顶部填入 Key 点「保存」。Key 用 Windows DPAPI 加密，只有当前用户能解密。

**环境变量**（适合脚本）：

```bash
set DESKTOP_AGENT_API_KEY=sk-xxxxxxxx
```

环境变量优先于本地文件。任何情况下 Key 都不会写进代码或仓库。

## 3. 启动

```bash
desktop-agent
```

界面从上到下：API Key、目标窗口（点「刷新」重新扫描）、指令输入框、开始/停止、运行日志。

## 4. 写指令的建议

指令越具体，成功率越高。

| 差的写法 | 好的写法 |
| --- | --- |
| 整理一下表格 | 把 A1、A2、A3 三个单元格都填入数字 1 |
| 改改文档 | 把文档里的全部内容替换成：本周完成三项任务。 |
| 做个 PPT | 新增一页幻灯片，把它的标题设为「项目总结」 |

要点：

- 明确**目标位置**（哪个单元格、哪一段）
- 明确**最终状态**（替换成什么、数量多少）
- 一次只交代一件事

## 5. 中断

任何时候按 `Ctrl+Alt+F12` 立即中断。界面上也有「停止」按钮。

如果进程卡死（极少见），新开一个终端执行：

```bash
taskkill /f /im python.exe
```

## 6. 运行记录

每次运行都会在 `~/.desktop-agent/runs/<时间戳>/` 下留一份记录：

- `events.jsonl`：每一步的决策、动作、耗时、是否成功
- `frames/`：每步的窗口截图
- `meta.json`：任务、状态、token 用量

想复现或排查问题时先看这里。记录可随时整目录删除。

## 7. 技能（可选）

一次成功的任务会自动存成技能，下次同样的指令直接重放，**零 API 调用**。

- 位置：`~/.desktop-agent/macros/`
- 删除某个技能：直接删对应 json 文件
- 全部重学：清空该目录

## 8. 常见问题

**界面能打开但点击没反应**：目标窗口可能不在前台。先手动点一下目标窗口，再点「开始」。

**提示找不到元素**：某些软件（游戏、自绘界面）不暴露无障碍树。此时它会自动改用截图识别，但精度会下降。

**API 报 401**：Key 无效或已过期，重新填一次。

**想换模型**：编辑 `~/.desktop-agent/config.json` 里的 `model` 和 `base_url`，支持任何 OpenAI 兼容接口。
